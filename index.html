crow.code
a terminal-first AI dev agent

One terminal. Every model. A whole dev environment underneath.

crow.code is a Python coding agent that lives in your terminal — it reads and edits files, runs your shell, drives git, and can hand different parts of the same project to different AI models at once.

Runs locally · Python · works with Claude, OpenAI, Grok, OpenRouter, or a custom endpoint
› crow /plan refactor the auth module
planning across 3 files…
› crow /gi review this before I ship it
› crow /hackit audit for security issues
› crow /undo
session restored — nothing lost

Talk to every model, not just one

Switch providers mid-conversation without losing context, or split one project across several models at once — each working a different piece in parallel.

Any provider, one interface

Anthropic, OpenAI, Grok, OpenRouter, or a custom endpoint — plug in the model you want and keep the same workflow.

Model switching, mid-session

Change which model is answering without restarting the conversation. The context carries over.

Parallel multi-AI tasks

Assign different models to different jobs in the same project — one writes code, another writes the docs, another reorganizes the folder structure.

Image input

Hand the agent a screenshot or diagram and let it reason about what it sees, not just what you typed.

A full dev environment, not a chat box

crow.code doesn't just suggest changes — it can make them, test them, and ship them.

File tools

Reads, writes, and navigates your project's files as part of the same conversation.

Shell execution

Runs real commands in your terminal — no copy-pasting suggested snippets by hand.

Git integration

Works with your repo directly — diffs, commits, and history are part of its context.

Automatic test execution

Runs your test suite after changes, so you find out immediately if something broke.

Skills system

Teach it repeatable playbooks for the tasks you do often, so it doesn't relearn them every time.

Gmail sending

Can send email directly — handy for reports, notifications, or handoffs at the end of a task.

Commands that do the heavy lifting

A set of slash commands cover the moments a normal coding session actually needs.

/plan
Lay out an approach before touching any code.
/diff
See exactly what changed, in context.
/undo
Roll back the last change, cleanly.
/bypassy
Auto-approve actions when you trust the plan.
/hackit
Run a security audit on the current code.
/ultramode
Give the agent broader control of the local machine.
/gi
Get a multi-persona review — several points of view on the same code.
